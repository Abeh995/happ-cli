# راهنمای جامع فارسی کار با Happ CLI (اپلیکیشن ترمینال و دیمن پس‌زمینه)

این راهنما آموزش کامل استفاده از **Happ CLI** در محیط ویندوز (PowerShell / CMD) است. شما می‌توانید هم از **منوی تعاملی (TUI)** استفاده کنید و هم دستورات را به صورت **تک‌خطی** اجرا نمایید.

---

## 🌟 اصل کلیدی: اتصال دائمی در پس‌زمینه (Daemon)
> [!IMPORTANT]
> وقتی با دستور `happ connect` یا از طریق منوی تعاملی وصل می‌شوید، هسته فیلترشکن به صورت یک **سرویس پس‌زمینه مستقل (Background Daemon)** اجرا می‌شود.  
> **اگر منوی برنامه یا کل پنجره پاورشل را ببندید، اتصال VPN هرگز قطع نمی‌شود.** ترافیک سیستم همچنان امن باقی می‌ماند تا زمانی که خودتان دستور `happ disconnect` را بزنید.

---

## 🚀 حالت‌های اتصال: TUN Mode در برابر System Proxy

سیستم Happ CLI از دو نوع اتصال مختلف پشتیبانی می‌کند:

1. **حالت TUN Mode (پیش‌فرض پیشنهادی):**
   - **پوشش ۱۰۰٪ تمام سیستم:** ترافیک کل سیستم (تمام مرورگرها، تلگرام، دیسکورد، ترمینال، دانلود منیجرها و بازی‌ها) از طریق آداپتور شبکه مجازی لایه ۳ (`happ-cli-tun`) و هسته Wintun عبور می‌کند.
   - **رفع کامل مسمومیت DNS:** ترافیک پورت ۵۳ سیستم ربوده شده و از درون تونل امن رمزنگاری‌شده ارسال می‌شود.
   - **سطح دسترسی:** نیازمند باز کردن ترمینال یا پاورشل به صورت **Run as Administrator** است.

2. **حالت System Proxy Mode:**
   - صرفاً ترافیک مرورگرها و نرم‌افزارهایی که از پروکسی سیستم ویندوز (WinINet) تبعیت می‌کنند هدایت می‌شود.
   - نیازی به دسترسی Administrator ندارد.

## ۱. نحوه باز کردن اپلیکیشن تعاملی (منوی گرافیکی در ترمینال)

کافیست در هر پنجره پاورشل یا CMD فقط تایپ کنید:

```powershell
happ
```

یک داشبورد کامل در ترمینال باز می‌شود:
```text
┌──────────────────────────────────────────────────────────────┐
│                  HAPP VPN TERMINAL DASHBOARD                 │
├──────────────────────────────────────────────────────────────┤
│  Status:       ● CONNECTED (Background Daemon Running)       │
│  Connection:   TUN Mode (Virtual Adapter: happ-cli-tun)      │
│  Active Server:#2 🇩🇪 Frankfurt                               │
│  Daemon PIDs:  Xray: 14220 | TUN: 15304                      │
│  System Proxy: Disabled (Direct - Not needed in TUN)         │
│  Admin Privs:  Yes (Elevated)                                │
│  Total Nodes:  118                                           │
├──────────────────────────────────────────────────────────────┤
│  [1] ⚡ Connect (Start Background VPN)                         │
│  [2] 🛑 Disconnect (Stop VPN & Revert Direct)                 │
│  [3] 🌐 Select Server (Browse 118 servers)                   │
│  [4] 🔄 Update Subscription (Refresh Servers)                 │
│  [5] ➕ Add New Subscription Link                             │
│  [6] 📶 Ping Servers (Latency Test)                           │
│  [7] 🔀 Switch Mode (Current: TUN)                           │
│  [8] 📋 View Detailed Status & Public IP                      │
│  [0] 🚪 Exit Terminal App (VPN stays connected!)             │
└──────────────────────────────────────────────────────────────┘
Choose option [0-8]: 
```

* **کلیدهای منو:** کافیست عدد گزینه مورد نظر را بزنید و Enter کنید.
* **تغییر مود اتصال (گزینه ۷):** تنها با یک کلید بین حالت **TUN** (کل سیستم) و **Proxy** (مرورگرها) سوییچ کنید.
* **انتخاب سرور (گزینه ۳):** لیست سرورها به صورت صفحه‌بندی‌شده نمایش داده می‌شود. با زدن شماره سرور آن را انتخاب می‌کنید، با `n` به صفحه بعد و با `p` به صفحه قبل می‌روید.
* **خروج از اپلیکیشن (گزینه ۰ یا q):** از منو خارج می‌شوید، اما **اتصال اینترنت قطع نمی‌شود**.

## ۲. استفاده از فرامین تک‌خطی (بدون باز کردن منو)

اگر نمی‌خواهید وارد منو شوید، تمام کارها با یک دستور مستقیم قابل انجام است:

### الف) مدیریت حالت اتصال (TUN یا Proxy)
```powershell
# مشاهده حالت فعلی اتصال:
happ mode

# تنظیم حالت پیش‌فرض روی TUN (کل سیستم):
happ mode tun

# تنظیم حالت پیش‌فرض روی پروکسی سیستم (مرورگرها):
happ mode proxy
```

### ب) افزودن لینک سابسکرایب (حاوی ۱۱۸ سرور)
```powershell
happ sub add "https://dash.cyberpower.space/guards/173d5ef57198aa54e09acc39d32bef57#8556_abeh"
```

### ج) مشاهده لیست سرورها
```powershell
# مشاهده صفحه اول سرورها:
happ list

# مشاهده صفحه دوم:
happ list 2
```

### د) انتخاب سرور (با شماره یا با نام)
```powershell
# انتخاب با شماره:
happ select 2

# انتخاب با نام کشور/شهر:
happ select "Frankfurt"
happ select "Amsterdam"
```
*(اگر در همان لحظه وصل باشید، بلافاصله اتصال شما به سرور جدید سوییچ می‌شود).*

### ه) اتصال به وی‌پی‌ان
```powershell
# اتصال با آخرین سرور و مود ذخیره‌شده:
happ connect

# اتصال با تعیین صریح مود اتصال:
happ connect --tun
happ connect --proxy

# یا اتصال مستقیم به سرور شماره ۵:
happ connect 5
```

### و) قطع اتصال
```powershell
happ disconnect
```

### ز) بررسی وضعیت اتصال و آی‌پی
```powershell
happ status
```

### ح) به‌روزرسانی لیست سرورها از اینترنت
```powershell
happ sub update
```

### ط) تست پینگ
```powershell
# پینگ پیش‌فرض:
happ ping

# پینگ همه سرورها:
happ ping all

# پینگ آدرس دلخواه:
happ ping 1.1.1.1 53
```

## ۳. جدول چیت‌شیت دستورات سریع

| دستور | نتیجه در ترمینال |
| :--- | :--- |
| `happ` | باز کردن داشبورد تعاملی منومحور (TUI) |
| `happ mode` | نمایش مود فعال اتصال (TUN یا Proxy) |
| `happ mode tun` | تغییر مود پیش‌فرض به TUN (کل ترافیک سیستم) |
| `happ mode proxy` | تغییر مود پیش‌فرض به System Proxy |
| `happ connect` | اتصال به سرور فعال در پس‌زمینه |
| `happ connect --tun` | اتصال صریح در حالت کارت شبکه مجازی (TUN) |
| `happ connect 3` | اتصال فوری به سرور شماره ۳ |
| `happ disconnect` | خاموش کردن VPN و بازگشت به اینترنت مستقیم |
| `happ status` | نمایش وضعیت اتصال، آی‌پی خروجی، کارت شبکه و کشور |
| `happ list` | لیست سرورها با شماره، پروتکل و پرچم کشور |
| `happ select 2` | انتخاب سرور شماره ۲ |
| `happ sub add <URL>` | افزودن لینک سابسکرایب جدید |
| `happ sub update` | به‌روزرسانی و دریافت کانفیگ‌های جدید |
| `happ ping all` | تست پینگ زنده سرورها |
| `happ help` | مشاهده راهنمای انگلیسی دستورات |
