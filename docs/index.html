⚡ 5-Second Windows Installation

Open PowerShell (Run as Administrator) and run:

powershell -c "irm https://raw.githubusercontent.com/Abeh995/happ-cli/main/windows/install.ps1 | iex"

This installs the global happ command into your system PATH and configures the Wintun adapter driver.

❓ Frequently Asked Questions (FAQ)

What is Happ Windows CLI?

Happ Windows CLI is the command-line and headless terminal edition of Happ VPN. It enables developers, sysadmins, and power users to control Xray proxies without heavy GUI overhead.

How does TUN Mode work on Windows?

Happ CLI initializes a virtual adapter (happ-cli-tun) through the high-performance Wintun kernel driver, intercepting Layer-3 IP packets and resolving all domain names through encrypted DoH resolvers.

Can I run Happ CLI in scripts or CI/CD?

Yes, all features are exposed as one-line CLI commands such as happ connect, happ disconnect, happ status, and happ ping all.
